# ClaimLens

An AI-powered cross-language fact-checking system that matches, analyzes, and verifies claims across multiple languages.

## Data Preparation

Run the following commands from the directory containing the scripts.

### 1. Scrape Data
Collect data by running:
```bash
python scraper.py
```

### 2. Clean Data
Clean the collected data by running:
```bash
python cleaner.py
```

### 3. Audit the Dataset
Audit the cleaned dataset by running:
```bash
python audit_dataset.py
```
