# ClaimLens

ClaimLens is an AI-powered cross-language fact-checking system that matches, analyzes, and verifies claims across multiple languages.

## Core capabilities

- **Cross-language claim matching**: maps semantically equivalent claims across languages.
- **Evidence analysis**: uses AI models to summarize and compare source evidence.
- **Verification pipeline**: assigns verification outcomes with confidence indicators.
- **Multilingual coverage**: supports intake, retrieval, and verification for claims written in different languages.

## High-level workflow

1. Ingest claims in any supported language.
2. Normalize and translate claims into a shared semantic space.
3. Retrieve and rank related multilingual evidence.
4. Analyze evidence consistency and factual support.
5. Return a verification result with rationale and confidence.
